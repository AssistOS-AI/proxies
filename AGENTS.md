# Repository Instructions

This repository contains proxy and gateway services, including Soul Gateway in `soul-gateway/`.

Each agent's documentation entry point is its `docs/index.html`, with canonical terminology in `docs/wiki.html` and contracts indexed by `docs/specs/matrix.md`. Its `DS001-coding-style.md` governs source and test organization. Update HTML documentation and the affected specifications together when behavior or interfaces change. DS frontmatter contains exactly `title` and `summary`; the title is the filename stem. `Introduction` and `Core Content` are the only top-level content sections. Keep rationale declarative, paragraphs unwrapped, and each Documentation Map aligned with its actual header submenus.

Code conventions:

- Use ES modules with `import` / `export`.
- Use four-space indentation for JavaScript and two-space indentation for JSON/YAML.
- Keep edits scoped to the relevant service; do not touch sibling repos, `node_modules/`, or unrelated untracked files unless explicitly asked.
- Never add `Co-Authored-By`, `Generated by`, tool-signature footers, or any other AI/coding-agent attribution to commits. Do not mention Claude Code, Codex, or any other coding agent in commit messages, PR descriptions, release notes, changelogs, code comments, metadata, or other project records in a way that reveals code was generated with a coding agent.
